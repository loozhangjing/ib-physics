# Question
The graph below represents the velocity $v$ against time $t$ of an object which is initially at rest and moves in a straight line. It is given that the areas $A_1$​ and $A_2$​ are $\pu{10 m}$ and $\pu{30 m}$ respectively.

![[ph1852q.png]]

At $t = \pu{10 s}$ the object is located at a distance $D$ from its starting point.

Which of the following correctly describes the value of $D$ and the average speed of the object from $t = \pu{0 s}$ to $t = \pu{10 s}$?
# Solution
$D = \pu{20 m}$
$\text{Average speed} = \pu{4 m s^-1}$
## Explanation
While at first glance it might seem like $D$ is the total distance travelled, which would be $10 + 30 = \pu{40m}$, $D$ is actually the distance from the **starting point**, i.e. the **displacement**, which is of course $10 + (-30) = 20 m$.

The average speed, however, is calculated by dividing the **total distance travelled** (which is not the value of $D$) by the total time ($\dfrac{10 + 30}{10} = \pu{4 m s^-1}$).
