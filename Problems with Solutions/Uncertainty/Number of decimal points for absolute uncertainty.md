# Question
What is the actual value of measurements $2.01, 2.09, 1.98, 2.05, 2.08$
# Solution
$$
\begin{aligned}
\text{Absolute uncertainty}
&= \dfrac{2.09 - 1.98}{2}\\
&= 0.055\\
&\approx 0.06\\
\\
\text{Measured value}
&= \dfrac{2.01 + 2.09 + 1.98 + 2.05 + 2.08}{5}\\
&= 2.042\\
&\approx 2.04\\
\therefore \text{Measurement} &= 2.04 \pm 0.06
\end{aligned}
$$
## Notes
- Absolute uncertainty must only have **one** significant figure\*.
- The measured value must have the same number of decimal points as the absolute uncertainty.

\*Unless the absolute uncertainty is greater than 1 before rounding, in which case it should have 2 significant figures, e.g. $\dfrac{\text{Range}}{2} = 1.79 \approx 1.8$
