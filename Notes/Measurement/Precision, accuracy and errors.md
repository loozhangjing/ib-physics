# Precision and accuracy

> [!quote] Definition
> **Precision** is how close to each other a set of measurements are.

Precision is related to the resolution of the measuring instrument.

> [!quote] Definition
> **Accuracy** is how close a set of measurements are to the actual value.
## In other words
- If you measure the same thing many times and get the same value, then the measurement is **precise**.
- If the measured value is close to the expected value, then the measurement is **accurate**.
